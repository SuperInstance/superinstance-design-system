## [0.1.0] — 2026-08-04

### Added
- Maritime-engineering design language for all SuperInstance projects
- Dual-platform: Web (CSS) and Roblox (Lua) implementations
- **Colors**: 6-color palette (Harbor, Water, Wood, Amber, Foam, Rust) with
  semantic aliases (Success, Warning, Danger, Info) and light/dark themes
- **Typography**: Inter/Gotham/Garamond/IBM Plex Mono scale (XS through Display)
- **Spacing**: 4px modular scale with UDim2 helpers, corner radius, gap/pad tokens
- **Motion**: Easing styles, duration scale, prebuilt TweenInfo tokens, stagger play
- **Components** (Lua): Button (4 variants), Card, Badge (6 variants), HUD, Input, Notification
- **Components** (CSS): Matching CSS implementations for all components
- Theme system with `GetTheme()` / `SetTheme()` runtime switching
